# @rovia/ui

Librairie de composants React accessible, au langage visuel **Drive × iOS** : la clarté tonale de
Google Drive et la douceur d'iOS. Construite sur **Radix UI** (comportement, clavier, ARIA) avec une
couche de style en **variables CSS** : aucune dépendance à Tailwind, thème clair et sombre natifs.

## Installation

```bash
pnpm add @rovia/ui
```

```tsx
// Une fois, à la racine de l'application
import "@rovia/ui/styles.css";
import { ThemeProvider, Toaster } from "@rovia/ui";

export function App({ children }) {
  return (
    <ThemeProvider defaultMode="light">
      {children}
      <Toaster />
    </ThemeProvider>
  );
}
```

Le thème sombre s'active par `ThemeProvider` ou par la classe `.dark` sur un parent : la librairie
fonctionne telle quelle avec `next-themes`. Les surcharges de jetons passent par
`<ThemeProvider overrides={{ pri: "#0b57d0" }}>`.

## Créer une application

Une application Next.js complète, prête en une commande : coque, connexion et inscription, tableau de bord, paramètres,
thème clair et sombre, français, anglais et arabe, palette ⌘K, pages système, SEO, tests et CI.

```bash
pnpm create next-app mon-app --example https://github.com/Luxus-Tempest/my-ui-kit/tree/starter/templates/next
```

L'authentification passe par un seul fichier, `lib/auth.ts` : branche y ton fournisseur. En attendant, une démonstration
accepte toute adresse (elle refuse de fonctionner en production).

## Blocs et éjection (registre)

Les **blocs** (écrans complets) s'installent dans ton application, copiés pour être modifiés
librement. Un **composant** peut aussi être éjecté : son seul dossier est copié, le reste continue de
venir du paquet. Les deux passent par le CLI shadcn, épinglé en <code>{SHADCN}</code> ; Tailwind
n'est pas nécessaire.

Mise en place, une fois par application (en plus de l'installation plus haut) : un `components.json`
à la racine. Avec un dossier `src/`, remplace `app/globals.css` par `src/app/globals.css` ; garde
`"rsc": true` (sinon le CLI retire `"use client"`).

<RegistrySetup />

Ensuite, chaque page de bloc ou de composant affiche sa commande, par exemple
<code>pnpm dlx {SHADCN} add @rovia/connexion</code>. Pour mettre à jour une copie, relance la même
commande avec `--overwrite`, puis relis la différence dans git.

## Principes

- **La variante est le rôle, jamais la couleur.** Une seule action primaire par vue.
- **Accessible par construction** : focus visible, clavier complet, états annoncés par ARIA, test axe pour chaque composant.
- **Jetons partout** : aucune valeur en dur, thème sombre conçu (pas inversé), contraste élevé et mouvement réduit respectés.
- **Composable** : `className` toujours accepté, `asChild` pour rendre un lien, `Field` relie n'importe quel contrôle à son libellé.
