# Statut des composants

- **Stable** : API figée (changement cassant = version majeure), testé, documenté, vérifié en clair, en sombre et de droite à gauche.
- **Bêta** : utilisable en production ; l'API peut encore évoluer sur retour d'usage (signalé dans le changelog).

Tous les composants ont un test de comportement et un test d'accessibilité (axe), et une page dans *Composants*.
Chaque composant n'importe que ce qu'il utilise : une application qui n'affiche aucun graphique n'embarque pas ECharts,
une application sans tableau de données n'embarque pas TanStack Table.

## Thème et hooks

| API | Statut | Notes |
|---|---|---|
| ThemeProvider | Stable | Clair, sombre, système ; `dir="rtl"` ; `density` (compacte, standard, confortable) |
| LocaleProvider, useLocale, useMessages | Bêta | Langue de l'interface : locale `Intl` et catalogue (`localeEn`, `localeAr`) |
| DirectionProvider, useDirection | Bêta | Sens de lecture transmis aux primitives Radix |
| useMediaQuery, breakpoints | Bêta | `sm` 640, `md` 768, `lg` 1024 px |
| useControllableState | Bêta | Valeur contrôlée ou non, pour vos propres composants |
